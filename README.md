## Après avoir cloné notre repositoire, vous allez voir 2 fichiers : frontend et backend
### Exécution frontend :
#### cd frontend
#### npm start (démarrer l'application localement - localhost:3000)
### Exécution backend :
#### cd backend
#### npm run server (nodemon) ou npm run start (exécution sur localhost:5000 par défaut)
